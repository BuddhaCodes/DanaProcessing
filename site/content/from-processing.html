Most of what you know carries over: same functions, same order of thinking, Setup() once and Draw() every frame. The differences are mostly C# itself. These are the ones that trip people up in the first hour.

The differences that matter

In DanaProcessingWhy it matters
Names are PascalCase: Fill, MouseX, FrameCountC# convention. Lowercase fill() is a compile error with a clear message.
Your sketch is a class: public class MySketch : SketchProcessing hides that class from you; here you write it. Variables you keep between frames are fields of that class.
public override void Draw()Setup, Draw and every event (MousePressed, KeyPressed…) are overrides. The editor completes them for you.
Decimal literals need f: 0.5fMost of the API uses float, and C# reads 0.5 as double.
5 / 2 is 2Integer division, like Java, unlike JavaScript. Write 5 / 2f for 2.5.
Color is a type, not an intColor c = Color(255, 0, 0); read channels with c.R or Red(c).
PVector is a value (a struct)Copying it copies the numbers, so var a = b; a.X = 5; doesn't change b. It has + - * / operators.
Rotate() takes radiansAs in Processing. RotateDegrees() is there when degrees read better.
Mouse state vs mouse eventsProcessing's mousePressed is both a variable and a function; here the variable is IsMousePressed and the event is MousePressed(). Same for keys.
List<T>, LINQ, $"...", NuGetAll of .NET is available: generic lists, string interpolation, async, and any NuGet package with a // nuget: line.

A sketch, ported

Processing's classic bouncing ball, line for line. Left out: nothing.

// Processing                          // DanaProcessing
float x = 100, vx = 3;                 // float x = 100, vx = 3;      (fields)
void setup() {                         // public override void Setup() {
  size(400, 200);                      //     Size(400, 200);
}                                      // }
void draw() {                          // public override void Draw() {
  background(30);                      //     Background(30);
  x += vx;                             //     x += vx;
  if (x < 20 || x > width - 20)        //     if (x < 20 || x > Width - 20)
    vx = -vx;                          //         vx = -vx;
  ellipse(x, height / 2, 40, 40);      //     Ellipse(x, Height / 2, 40, 40);
}                                      // }
Run it: the same sketch, complete:
public class Bounce : Sketch
{
    float x = 100, vx = 3;

    }
