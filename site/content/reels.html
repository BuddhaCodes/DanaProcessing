Mark up your sketch with // @reel comments and the IDE turns it into a short video for Reels, Shorts or TikTok. You get a title card, the code typing itself scene by scene with captions and highlighted lines, then the sketch running live, even driven by a simulated user if it reacts to the mouse or keyboard. Open it from Sketch → Create reel...

using DanaProcessing.Reels;   // opt in: hidden from the video

// @reel title: Particles that chase your mouse
// @reel format: vertical
// @reel result: 8 caption="Move to steer · click to burst"

// @reel scene "Every frame, each one steers toward the mouse" effect=type
public override void Draw()
{
    // @reel pause 0.4
    pull.SetMag(0.35f);   // @mark  (highlighted once typed)
    // @reel hide
    ...bookkeeping you don't want on screen
    // @reel show
}

// @reel drag 100,100 -> 500,400 at=2 dur=1.5

Reel settings → // @reel key: value

Put these anywhere, usually at the top. All are optional.

markerwhat it does
title: … / subtitle: …Opening title card, also shown as a header over the code cards
format: vertical | square | landscape1080×1920 (default), 1080×1080 or 1920×1080
theme: clay | dark | lightClay is the IDE's own look (default)
speed: 55 | slow | normal | fast | turboTyping speed in characters per second. If you don't set it, long scenes speed up to stay reel-sized
result: 8 caption="…" transition=zoomSeconds of live sketch at the end; result off skips it
outro: … | offClosing card text, or none
fps: 30 · lang: en | es · file: Sketch.csFrame rate, language of the reel's own labels, file name on the code card
progress: off · linenumbers: off · mouse: offHide the story-style progress bar, the line numbers, or the simulated mouse
typos: on | 10% | offTyping now and then hits a neighbouring key, notices and backspaces, like a person. on is about one word in twelve. Off by default; per scene with typos=
zoom: offLines marked with // @mark get a gentle zoom while they're highlighted (default on); off keeps the card still
audio: on | offRecord the sketch's sound (live loops, Play(), samples) into the MP4. On by itself when the code makes sound

// @reel scene "caption" → a code card

The code from this marker to the next one is one card, with its caption underneath. Options: effect=type|lines|fade|instant (typed with a caret, line by line, all at once with a fade, or already there), transition=slide|fade|zoom|wipe|none, speed=, hold= (seconds the finished card stays), typos= (this card's own typo rate), and the word keep to continue the previous card instead of starting a new one. A scene with a caption and no code becomes a full-screen statement card. Indentation is normalized per card. A line too long for the card wraps onto extra rows (shown with a dot instead of a line number), the way an editor soft-wraps, instead of shrinking the code until a phone can't read it.

Inside a scene → pause · caption · @mark · hide/show

// @reel pause 0.5 stops typing for a moment before the next line. // @reel caption: … changes the caption when the next line starts appearing. Ending a code line with // @mark highlights it once the scene is shown and dims the rest. Lines between // @reel hide and // @reel show still compile and run, but never appear in the video.

Simulated interaction → move · drag · click · key

During the result part the sketch receives real input events (MousePressed(), MouseDragged(), KeyPressed()…), and the video draws the cursor, click ripples and a keycap. Points are in sketch pixels and times in seconds since the result started: // @reel move 10,10 -> 200,200 -> 300,50 at=1 dur=2, // @reel drag 100,100 -> 400,300 at 3s over 1.5s, // @reel click 300,200 at=2, // @reel key space at=4 (also enter, arrow keys, or any single character). With no scripted mouse, a sketch that reads the mouse gets a natural-looking path automatically, plus clicks and a drag if it overrides those methods.

Export → MP4 · GIF · PNG

The preview window plays the reel and lets you scrub and jump to any part. Export renders frame by frame in video time, not real time, so a heavy sketch still comes out smooth, and Millis() follows video time. MP4 (H.264, full resolution) needs ffmpeg; the window finds it or lets you pick it. GIF uses DanaProcessing's own encoder and needs nothing else. PNG writes one image per frame for your own editor. If the sketch makes sound, it's recorded in step with the video: live loops run in video time, so every beat lands on the same frame as in the preview, and the MP4 gets an AAC track (PNG export drops an audio.wav next to the frames; GIF has no sound). YouTube thumbnail… saves a 1280×720 PNG with the reel's title, a frame of the running sketch and the reel's theme, so the video and its thumbnail match.

Reel.IsActive → bool · Reel.IsExporting → bool

True while your sketch's code is running inside a reel (preview or export), or while a reel is being written to a file. Use them to skip a slow intro or hide debug text in the video. Reel.Parse(source) returns the parsed ReelScript (scenes, inputs, warnings) if you want to build tooling on top.

Try it: Sketch → Examples, tag Reels / video: "Reel: particles that chase your mouse" (vertical, auto-simulated mouse) and "Reel: a paint app in 25 lines" (square, dark theme, scripted drags and a key press), "Reel: typing with mistakes and backspace" (typos for the reel and per scene) and "Reel: zoom on marked lines" (// @mark with zoom).

Runnable example

A complete sketch using this section. Test in Dana opens it in the IDE, or paste it into a new tab and press Run.

// @reel title: A circle that follows you
// @reel format: vertical
// @reel result: 6 caption="Move the mouse"
// @reel scene "Every frame, ease toward the mouse" effect=type
public class FollowReel : Sketch
{
    float x = 200, y = 200;

    public override void Setup() => Size(400, 400);

    public override void Draw()
    {
        Background(25, 28, 40);
        x = Lerp(x, MouseX, 0.1f);   // @mark
        y = Lerp(y, MouseY, 0.1f);   // @mark
        Fill(255, 180, 120); NoStroke();
        Circle(x, y, 60);
    }
}
// Open it, then Sketch > Create reel... to preview and export the video.
